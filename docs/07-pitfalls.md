# 坑清单

## 九、坑清单

| 现象 | 原因 | 处理 |
|---|---|---|
| 每句话结尾都上扬 | 参考音频是问句 | 换陈述句当主参考 |
| 音色像但语调很平 | GPT 没训够 | 加 GPT 轮数 |
| 重复字、漏字 | 台词和音频错位 | 重新核对 list，一句一音频 |
| 声音发闷 | 训练集 48kbps 本身带宽窄 | 换 v4 能原生输出 48k，但 v4 对低质量集更差，权衡后再定 |
| 中文里夹英文字母读得很怪 | 只学过日语的模型 | 在 `anomalous_tts.json` 的 `replace` 里写成假名/汉字 |
| 双击 `go-webui.bat` 闪退 | 它找 `runtime\python.exe`，本机没有 | 用 `..\env\Scripts\python.exe webui.py zh_CN` |
| 装节点时 pyopenjtalk 编译失败 | 用了非 3.13 环境或缺编译器 | 本机 ComfyUI 是 3.13，有现成轮子 |
