# 原理与选型

## 一、它怎么工作的（理解这个才不会白折腾）

GPT-SoVITS 是**两段式**，两个模型各管一半：

```
台词文本 ──┐
           ├─→ [GPT 模型] ─→ 语义 token 序列 ─┐
参考音频 ──┘   （管"怎么说"：韵律/语流/情绪）  │
                                              ├─→ [SoVITS] ─→ 语音
参考音频 ────→ 音色向量 ─────────────────────┘   （管"谁在说"）
```

- **SoVITS（声学模型）**：拿「音素 + 音色向量」生成梅尔频谱。音色像不像，靠它。
- **GPT（语言模型）**：拿「参考音频的语义 token + 你的文本」预测目标语义 token。自然不自然、有没有口音、会不会重复漏字，靠它。

由此推出三条硬规则，全是原理决定的，不是格式要求：

1. **参考音频 3–10 秒就够**，因为音色向量只需要很短的样本。
2. **参考音频必须有台词**（v3/v4 强制）。因为 GPT 要知道那 10 秒说的是什么，才能把文本和音频对齐。没有台词就等于让它猜。
3. **参考音频的语气会感染全部输出**。拿问句当参考，每句结尾都会上扬。这是最常见的"怎么听着怪怪的"原因。

## 二、零样本 vs 微调

| | 零样本 | 微调（我们要做的） |
|---|---|---|
| 需要训练吗 | 不用 | 要 |
| 数据量 | 一条 3–10 秒音频 | 1 分钟起步，5–10 分钟较好 |
| 音色相似度 | 六七成，有口音 | 明显更稳、更像 |
| 情绪控制 | 只有一条参考的语气 | 可以给每个情绪配一条参考 |
| 用途 | **验证值不值得投入** | 正式用 |

**先做零样本**。它能在 30 分钟内告诉你这套东西的上限在哪，避免训完才发现不满意。

## 十、时间与预期

| 阶段 | 耗时 | 产出 |
|---|---|---|
| 零样本试听 | 30 分钟 | 3–5 条 Kei 念台词，判断值不值得 |
| 装 Anomalous_TTS | 15 分钟 | ComfyUI 里能选角色 |
| 抓数据 + 对台词 | 1–2 小时 | 148 条音文配对 |
| 切片 + 清洗 | 30 分钟 | 干净的训练集 |
| 训 v2 | 40–60 分钟 | SoVITS + GPT 权重 |
| 验收 + 调参 | 30 分钟 | 可用模型 |

**预期效果**：10 分钟数据训 v2，日常台词能听、像 Kei，但会有轻微口音、长句偶有瑕疵。想更好只能加数据（剧情语音那种长句），不是加轮数。
