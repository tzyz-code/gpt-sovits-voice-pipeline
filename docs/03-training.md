# 训练

## 三、版本怎么选（这条很关键，选错白干）

官方文档原话：

> 对于平均音频质量较低的训练集，**V1/V2/V2Pro 可以取得较好的效果，但 V3/V4 无法做到**。
> 此外，V3/V4 合成的声音**更偏向参考音频**，而不是整体训练集的风格。

我们手上的素材是 wiki 的 **48kbps Ogg Vorbis**——这属于"低质量"。所以：

| 版本 | 结论 |
|---|---|
| v1 / v2 | ✅ **先跑通这个**。底模本机已有（`gsv-v2final-pretrained`），零下载 |
| v2Pro | ✅ **最终目标**。官方称性能超过 v4，硬件成本同 v2，需另下约 1GB 底模 |
| v3 | ❌ 低质量训练集效果差，且只原生输出 24k（发闷） |
| v4 | ❌ 同上。48k 输出是优点，但训练集质量跟不上就没意义 |

路线：**v2 打通 → 满意后换 v2Pro 重训一次**。

## 六、训练步骤（WebUI，不是命令行）

启动：

```
cd /d <gpt_sovits_root>
..\env\Scripts\python.exe webui.py zh_CN
```

浏览器开 `127.0.0.1:9874`（或控制台提示的地址），按左侧 0/1/1A/1B 顺序走：

| 步骤 | 做什么 | 注意 |
|---|---|---|
| **0-一键三连** | 填音频目录 → 切片 → ASR → 校对 | **ASR 跳过**，直接改 `list` 文件 |
| **1A-训练 SoVITS** | `batch_size=6`，`total_epoch=8` | 8G 显存够；轮数别拉太高，10 分钟数据过拟合很快 |
| **1B-训练 GPT** | `batch_size=4`，`total_epoch=15` | 比 SoVITS 慢，显存吃得多 |
| **1C-推理** | 选权重 + 参考音频 + 参考台词 → 合成 | 就是验收 |

参数说明（官方没给表，以下是社区通行值 + 本机经验）：

| 参数 | 建议 | 理由 |
|---|---|---|
| SoVITS `total_epoch` | 8（数据少就 10） | 10 分钟数据，超过 15 轮开始过拟合，听着"糊" |
| SoVITS `batch_size` | 6 | 8G 显存上限附近 |
| GPT `total_epoch` | 15 | 主要影响韵律自然度 |
| GPT `batch_size` | 4 | 再大显存吃紧 |
| `if_save_latest` | 开 | 只留最新，省磁盘（C 盘只剩 13G） |

**判断训练够不够**：每轮会存 `SoVITS_weights_v2/xxx_e8_sxxx.pth`。听 `1C` 里用不同轮次的权重合成同一句话，挑最像的——不一定是轮数最大的。
